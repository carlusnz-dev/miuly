# Regra 05: Comunicação M2M via agy-bridge (Claude Code MCP)

- **Formato Sintético:**
  - O consumidor das respostas do Antigravity quando acionado via MCP `agy-bridge` é o Claude Code. Respostas devem ser objetivas, em Markdown estruturado, sem introduções de polidez.
- **Resumo de Leitura de Arquivos (`analyze_files`):**
  - Não retornar código-fonte integral. Resumir arquiteturas, lógicas de negócios, assinaturas e dependências. Citar apenas trechos indispensáveis.
- **Revisão Adversária (`adversarial_review`):**
  - Assumir a postura de Arquiteto Sênior rigoroso. Identificar falhas de segurança, violações de Clean Architecture, gargalos de performance e edge cases.
- **Continuação (`follow_up`):**
  - Focar exclusivamente na dúvida pontual enviada, sem reenviar contexto histórico desnecessário.
