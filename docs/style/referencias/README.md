## Técnica local do mesh

O trecho recebido para referência era o iframe `<iframe src="https://colorflow-embed.b-cdn.net/embed.html#e=kXdoMSkN" width="1600" height="1200" frameborder="0"></iframe>`. O componente local `components/ui/mesh-gradient/` usa camadas CSS de `radial-gradient` em tons de verde e uma camada SVG própria com `feTurbulence` como ruído. Apenas um pseudo-elemento amplo se move lentamente por `transform`; não há canvas, Three.js, download ou requisição ao embed. Em `prefers-reduced-motion: reduce`, o gradiente permanece estático.
