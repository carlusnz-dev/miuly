# Infraestrutura

Espaço reservado para recursos reproduzíveis de ambiente, banco, observabilidade
e implantação. Ainda não há infraestrutura executável versionada.

Arquivos futuros devem separar ambientes, documentar variáveis sem valores
secretos, fixar versões relevantes e oferecer validação local antes de qualquer
implantação. Credenciais, tokens OAuth, chaves e dados pessoais não devem ser
armazenados neste diretório.
